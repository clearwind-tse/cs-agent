# 小蚕惠生活销售意图识别技能

## 技能说明

本技能用于**客服对话意图识别与分类**，基于小蚕惠生活平台业务场景。

## 适用场景

- 客服会话质检：判断客服是否完成售前引导
- 工单自动分类：依据对话内容打标签
- 话术优化：识别高频问题类型分布

## 意图分类体系

| 意图类型 | 说明 |
|---------|------|
| `savings_explain` | 省钱讲解类：向客户介绍如何省钱 |
| `rebate_query` | 返利查询类：客户询问返利规则或进度 |
| `coupon_issue` | 优惠券问题：优惠券领取/使用异常 |
| `order_problem` | 订单问题：订单状态/修改/取消 |
| `complaint` | 投诉处理：客户表达不满或投诉 |
| `merchant` | 到店霸王餐：到店兑换相关咨询 |
| `brand_promo` | 品牌活动：品牌促销活动咨询 |
| `points_box` | 积分盲盒：积分玩法与盲盒活动 |
| `onboarding` | 新人引导：新客注册引导与入门帮助 |

## 使用方法

在对话分析场景下，将此技能挂载到 agent 的 `supported_intents` 中，配合 `extractor_agent` 进行意图抽取。
